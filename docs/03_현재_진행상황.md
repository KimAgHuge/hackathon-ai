# 현재 진행상황

기준일: 2026-10-22. 현재 구현과 마지막 실행 확인을 요약합니다.
실시간 작업 상태는 웹 화면과 연결된 서버의 상태 조회를 기준으로 확인합니다.

## 구현된 주요 기능

| 영역 | 현재 구현 |
| --- | --- |
| 인증·접근 제어 | Supabase 로그인, 사용자 프로필·역할·권한 조회, 메뉴·화면 제어, 백엔드 권한 검사 |
| 조직·프로젝트 | 조직 조회·생성, 조직 구성원 API, 프로젝트 등록·조회·수정·논리 삭제·복구 |
| 연결·근거 수집 | Git 인증·연결 검사, 읽기 전용 DB 연결, 고정 Git 버전과 DB 구조 수집 |
| 요구사항·분석 | 요구사항 버전·후속 답변, 비동기 분석, 단계·이력 조회, 취소, 저장 결과 재열기 |
| 분석 검토·학습 자료 | 원본 또는 수정본 검토 결정, 승인 자료 초안·검증·전달, 분석 모델 출처 보존 |
| 모델 작업 | 설치 모델 조회, JSON 응답 검증, 모델 전환·직전 모델 복구, 선택 모델별 학습·취소 |
| 학습 대상·이어 학습 | 선택 모델 ID와 등록 프로필 전달, 로컬 부모 작업·기반 파일 검증, 새 작업에 어댑터 저장 |

모델 작업은 한 모달에서 **분석에 사용 / 선택 모델 학습 / 학습 결과 적용**으로 진행합니다.
독립 학습 탭은 제거했으며 학습 진행·결과·취소는 실행 작업 이력에서도 확인합니다.

## 공통 학습과 모델별 결과

프론트에서 선택한 모델 ID를 백엔드와 맥북 학습 서버의 조회·요청·이력까지 유지합니다.
승인 자료의 원래 생성 모델인 `sourceModel`과 실제 선택 모델인 `selectedModel`을 구분합니다.
기존 Qwen 시험기와 공통 `mlx-lora-v1`을 함께 지원하며, 모델마다 MLX 가중치·토크나이저·학습 프로필을 등록합니다.
공통 실행 코드를 사용하되 모델별 가중치와 어댑터는 따로 관리합니다. 미등록 모델을 Qwen으로 대체하지 않습니다.

완료한 파생 모델은 이 맥북의 부모 작업·어댑터·설정·기반 파일을 확인한 뒤 이어 학습합니다.
결과는 새 UUID에 저장하며 부모 어댑터나 운영 모델을 덮어쓰지 않습니다.
공통 GGUF 변환은 검토한 `llama`, `mistral`, `qwen2`, `qwen3`, `exaone4` 밀집 텍스트 구조에 허용하고,
학습 지원과 변환 지원을 별도로 판정합니다. 새 형식 2의 서명·프로필·GGUF 구조를 검증하며 기존 Qwen 형식 1도 유지합니다.

## 마지막 실제 확인

- Git·DB 수집을 거친 실제 요구사항 분석과 결과 저장·검토·학습 자료 전달을 확인했습니다.
- 기존 Qwen 승인 자료의 웹 시험 학습과 어댑터 저장·재로딩을 완료했습니다.
- 2026-10-21 맥북 학습 서버에서 완료한 Qwen 학습을 재사용해 기반 모델 병합·GGUF 변환·Q4_K_M 양자화·공유 폴더 게시를 완료했습니다.
- 스튜디오의 AI 분석/추론 서버에서 새 모델 등록이 공유 파일 동기화 대기로 확인된 기록이 있습니다.
  이후 등록·JSON 응답 검증·실제 모델 전환의 최종 성공은 이 맥북에서 확인하지 않았습니다.
- 작은 임의 Llama·EXAONE4를 4비트로 만든 CPU 검사에서 각각 새 학습 2회 업데이트·새 프로세스 재로딩·이어 학습 2회 업데이트·재로딩이 통과했습니다.
  부모 파일 해시는 유지됐고 확인 출력 차이는 0이었습니다. 실제 대형 모델 학습이나 전체 GGUF 변환의 성공을 뜻하지 않습니다.

2026-10-21~22 공통 학습 변경에서 완료한 자동 검사는 다음과 같습니다. 이번 문서 병합에서 새로 실행한 결과는 아닙니다.

| 별도 CPU 통합 | 작은 Llama·EXAONE4 새 학습·이어 학습·재로딩 통과 |

자동 검사와 짧은 JSON 검증은 실제 업무 정확도 향상을 증명하지 않습니다.

## 남아 있는 범위

- 사용자별 전역 역할 부여·회수와 역할별 권한 편집을 위한 관리 화면·전용 API는 없습니다.
  현재 역할·권한에 따른 접근 검사는 구현돼 있으며, 조직 구성원 API와는 별도입니다.
- 실제 대형 모델 학습·완성 모델 생성은 기존 Qwen 경로에서 확인했습니다.
  실제 EXAONE 등 다른 대형 모델의 가중치 설치·학습·변환·긴 입력·업무 품질 평가는 남아 있습니다.
- 현재 웹 요청은 1~20회 업데이트의 짧은 시험 학습입니다. DB 단계별 학습 입력 복원과 독립 생성 품질 평가는 남아 있습니다.
- 한 작업 안에서는 같은 원 요구사항의 수정 버전·후속 질문을 학습과 평가에 나눠 섞지 않습니다.
  이어 학습 작업 사이에서도 부모·조상 작업의 분할을 고정해 학습·평가 자료가 서로 이동하지 않도록 보완해야 합니다.
- 승인 초안은 실제 변환된 입력으로 답할 수 있는 정답인지 사람이 확인해야 합니다.
  DB 상세 근거가 일반 분석 정답에 섞이거나, 인용 파일이 변환 입력에서 빠진 자료는 그대로 학습하지 않습니다.
- 새 모델 생성의 저장 공간 조건은 아직 180 GiB로 고정돼 있습니다. 모델별 중간 파일 크기를 반영하는 조건으로 바꾸는 작업이 남아 있습니다.
- 아키텍처·영향도 화면에는 예시 자료가 남아 있습니다. 문서 업로드·서버 설정 화면은 현재 메뉴에서 제외합니다.
- 견적 작성·검토·고객 공개 전체 흐름은 제품의 후속 구현 범위입니다.

## 운영 안내

실행 중인 서버에는 파일 수정만으로 새 코드가 반영되지 않습니다. 진행 작업이 없는지 확인한 뒤 재시작하며,
백엔드·스튜디오의 AI 분석/추론 서버·맥북 학습 서버에 같은 변경을 반영한 후 연결 시험을 진행합니다.
