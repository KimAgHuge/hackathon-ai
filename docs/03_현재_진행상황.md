# 현재 진행상황

기준일: 2026-10-21. 현재 구현과 마지막 실행 확인을 요약합니다.
실시간 작업 상태는 웹 화면과 연결된 서버의 상태 조회를 기준으로 확인합니다.

## 구현된 주요 기능

| 영역 | 현재 구현 |
| --- | --- |
| 인증·접근 제어 | Supabase 로그인, 사용자 프로필·역할·권한 조회, 메뉴·화면 제어, 백엔드 권한 검사 |
| 조직·프로젝트 | 조직 조회·생성, 조직 구성원 API, 프로젝트 등록·조회·수정·논리 삭제·복구 |
| 연결·근거 수집 | Git 인증·연결 검사, 읽기 전용 DB 연결, 고정 Git 버전과 DB 구조 수집 |
| 요구사항·분석 | 요구사항 버전·후속 답변, 비동기 분석, 단계·이력 조회, 취소, 저장 결과 재열기 |
| 분석 검토·학습 자료 | 원본 또는 수정본 검토 결정, 승인 자료 초안·검증·전달, 분석 모델 출처 보존 |
| 모델 작업 | 설치 모델 조회, JSON 응답 검증, 모델 전환·직전 모델 복구, 모델별 학습·취소 |
| 학습 결과 적용 | 완료 학습 선택, 새 모델 생성·취소·진행 조회, 스튜디오의 AI 분석/추론 서버 등록, 검증 후 적용 |
| 모델 관리 기록 | 모델 버전 등록, 상세·수동 평가 기록, 실행 작업 이력 |

모델 작업은 한 모달에서 **분석에 사용 / 선택 모델 학습 / 학습 결과 적용**으로 진행합니다.
독립 학습 탭은 제거했으며 학습 진행·결과·취소는 실행 작업 이력에서도 확인합니다.

## 마지막 실제 확인

- Git·DB 수집을 거친 실제 요구사항 분석과 결과 저장·검토·학습 자료 전달을 확인했습니다.
- 기존 Qwen 승인 자료의 웹 시험 학습과 어댑터 저장·재로딩을 완료했습니다.
- 맥북 학습 서버의 고정 변환 도구·설정·저장 공간 준비와 재시작을 확인했습니다.
- 완료한 학습을 재사용해 기반 모델 병합·GGUF 변환·Q4_K_M 양자화·공유 폴더 게시를 완료했습니다.
- 스튜디오의 AI 분석/추론 서버의 새 모델 등록은 공유 폴더 파일 동기화 대기로 확인했습니다.
  등록·JSON 응답 검증·실제 모델 전환이 끝까지 성공하는지는 동기화 후 확인해야 합니다.
- 프론트·백엔드·스튜디오의 AI 분석/추론 서버·학습 도구의 자동 검사를 통과했습니다.
  자동 검사와 짧은 JSON 검증은 실제 업무 정확도 향상을 증명하지 않습니다.

## 남아 있는 범위

- 사용자별 전역 역할 부여·회수와 역할별 권한 편집을 위한 관리 화면·전용 API는 없습니다.
  현재 역할·권한에 따른 접근 검사는 구현돼 있으며, 조직 구성원 API와는 별도입니다.
- 실제 학습·완성 모델 생성은 검증한 Qwen 구조에 한정됩니다. 다른 설치 모델을 선택할 수 있다는 사실이
  해당 모델의 학습 지원을 뜻하지 않습니다.
- 현재 웹 학습은 짧은 MLP 시험 학습입니다. DB 단계별 학습 입력 복원과 독립 생성 품질 평가는 남아 있습니다.
- 승인 초안은 실제 변환된 입력으로 답할 수 있는 정답인지 사람이 확인해야 합니다.
  DB 상세 근거가 일반 분석 정답에 섞이거나, 인용 파일이 변환 입력에서 빠진 자료는 그대로 학습하지 않습니다.
- 아키텍처·영향도 화면에는 예시 자료가 남아 있습니다. 문서 업로드·서버 설정 화면은 현재 메뉴에서 제외합니다.
- 견적 작성·검토·고객 공개 전체 흐름은 제품의 후속 구현 범위입니다.
