수정 유형: text-localization 및 infographic-diagram. 첨부한 doenaai 서버 구성도 PNG를 수정한다. 밝은 흰 배경, 파란색·보라색·연두색·연노랑 카드, 친근한 3D 장비와 사용자 그림, 진한 남색의 정확한 한글 글꼴을 유지한다. 제목은 'doenaai 서버 구성도'. 가로 16:9 구도로 만들고, 정확히 일곱 개 영역을 넉넉하게 배치한다. 상단 세 카드: 사용자 PC, 서비스 서버, AI 분석/추론 서버. 하단 네 카드: 분석할 프로젝트, 서비스 저장소, 공유 NAS 역할, AI 학습 서버. 필요한 경우 기존 카드의 크기와 위치를 조정해 모든 문구를 크게 읽을 수 있게 한다.

4. 하단 왼쪽 '분석할 프로젝트'. 설명 '소스코드와 DB 구조만 확인'. 기존 Git 폴더와 DB 그림. 하단 라벨 'Git 저장소', '대상 DB'.

정확한 연결과 방향을 지킨다.
실선: 사용자 PC → 서비스 서버 '분석 요청', 서비스 서버 → 사용자 PC '결과 화면'. 서비스 서버 → AI 분석/추론 서버 '정리된 근거 전달', AI 분석/추론 서버 → 서비스 서버 '분석 결과'. 분석할 프로젝트 → 서비스 서버 '소스·DB 구조 수집'. 서비스 서버 ↔ 서비스 저장소 '기록 저장·조회'.
보라색 점선: AI 분석/추론 서버 → 공유 NAS 역할 '학습 사례 게시'. 공유 NAS 역할 → AI 학습 서버 '학습 파일 수신'. AI 학습 서버 → 공유 NAS 역할 '평가된 모델 게시'. 공유 NAS 역할 → AI 분석/추론 서버 '모델 수신·검증·배포'. 마주 보는 점선은 나란히 분리하고 라벨은 화살표와 겹치지 않게 쓴다. 두 AI 서버의 직접 연결 화살표를 그리지 않는다. 학습 서버와 사용자 PC 사이에는 직접 연결을 그리지 않는다. Supabase와 iCloud Drive를 합치거나 Supabase에서 학습 서버로 바로 파일이 전송되는 화살표를 그리지 않는다.

하단 범례 '실선: 분석 흐름 · 점선: 학습·배포 흐름'. 별도 하단 안내 '대상 DB는 읽기 전용 · 최종 판단은 사람이 합니다'.
한글이 겹치거나 잘리지 않게 하고 충분히 큰 글씨로 정확히 렌더링한다. 필요하면 장비 그림을 조금 줄여 사양 줄과 화살표를 위한 여백을 확보한다. AI/AI 또는 분석/AI처럼 어색한 중복 이름을 쓰지 않는다. 서버 역할은 정확히 'AI 분석/추론 서버', 'AI 학습 서버'로 쓴다. 명시한 사양 외에 확인되지 않은 SSD 용량·뉴럴 엔진·제품 세부 모델을 추가하지 않는다. '미구현', '예정' 등 상태 표시는 추가하지 않는다. 불투명 배경의 완성 PNG 한 장을 만든다.

후속 수정: 장비 사양과 카드 디자인은 유지하고 모델 배포 화살표만 교정한다.
AI 학습 서버에서 AI 분석/추론 서버로 직접 올라가는 점선은 없앤다.
